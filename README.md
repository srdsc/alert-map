# Alerts Map AutoRefresh 

Простая обертка (wrapper) на базе HTML `iframe` и мета-тега `http-equiv="refresh"`, созданная для стабильного отображения интерактивной карты (https://alerts.in.ua) на телевизорах с LG webOS.

## Что сделано:
* **Автоматическое обновление:** Страница принудительно перезагружает фрейм каждые 5 минут (300 секунд), сбрасывая заснувшие и застрявшие WebSocket-соединения.
* **Обход ограничений webOS:** Решает проблему агрессивной очистки памяти и фоновой приостановки JavaScript-скриптов во встроенном браузере Smart TV.
* **Автономность:** Не требует использования внешнего ПК, установки сторонних плагинов или включения режима разработчика.
